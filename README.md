Première version du frontend d'une application de gestion de tâches, réalisée avec **React**, **TypeScript** et **Tailwind CSS**.

> ℹ️ Ce dépôt contient la **mise en place initiale** du projet (structure, routage, page de connexion). La version complète, avec backend et base de données, est disponible ici : **[interactive-task-manager](https://github.com/AyaElouajjite/interactive-task-manager)**.

---

## ✨ Contenu

- ⚙️ Configuration du projet avec **Vite** + **TypeScript**
- 🎨 Intégration de **Tailwind CSS** et **Headless UI**
- 🧭 **Routage** avec React Router et protection des routes (redirection vers la connexion)
- 🔐 **Page de connexion** avec validation des formulaires (React Hook Form)
- 📄 Pages prévues : tableau de bord, tâches, détail d'une tâche, utilisateurs, corbeille
- 🔔 Notifications avec Sonner

## 🛠️ Technologies

React 18 · TypeScript · Vite · Tailwind CSS · Headless UI · React Router · React Hook Form · Recharts · Sonner

## 🚀 Installation

**Prérequis :** Node.js 18+

```bash
git clone https://github.com/AyaElouajjite/TO-DO-list-.git
cd TO-DO-list-/vite-project
npm install
npm run dev
```

L'application est disponible sur l'adresse affichée par Vite (par défaut **http://localhost:5173**).
