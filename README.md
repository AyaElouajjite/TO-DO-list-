Prototype de l'interface d'une application de gestion de tâches, développé avec React, TypeScript et Tailwind CSS.

> **Remarque :** ce dépôt correspond à la phase initiale du projet (configuration, routage, authentification). La version complète, avec backend et base de données, est disponible dans le dépôt [interactive-task-manager](https://github.com/AyaElouajjite/interactive-task-manager).

## Réalisations

- Initialisation du projet avec Vite et TypeScript
- Intégration de Tailwind CSS et Headless UI
- Routage avec React Router et protection des routes (redirection vers la page de connexion)
- Page de connexion avec validation de formulaire (React Hook Form)
- Structure des pages : tableau de bord, tâches, détail d'une tâche, utilisateurs, corbeille
- Notifications avec Sonner

## Stack technique

React 18 · TypeScript · Vite · Tailwind CSS · Headless UI · React Router · React Hook Form

## Installation

**Prérequis :** Node.js 18 ou supérieur.

```bash
git clone https://github.com/AyaElouajjite/TO-DO-list-.git
cd TO-DO-list-/vite-project
npm install
npm run dev
```

L'application est accessible à l'adresse indiquée par Vite (par défaut `http://localhost:5173`).
